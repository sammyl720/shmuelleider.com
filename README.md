# shmuelleider.com

Personal portfolio for **Shmuel (Shmuli) Leider**.

Built with Next.js, TypeScript, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run typecheck
npm run lint
npm run build
```

Set `NEXT_PUBLIC_SITE_URL=https://shmuelleider.com` in production.
